# データ項目と連動

現行試作はJavaScriptオブジェクトをタブ内に保持する。以下の「現在」は実装済み。将来項目はDBへ実装済みという意味ではない。

## 現在：日報 `Report`

| 項目 | 型・必須 | 入力元／意味 |
| --- | --- | --- |
| `id` | 文字列・必須 | システム生成の一意ID。同じIDの修正は置き換える |
| `date` | `YYYY-MM-DD`・必須 | 作業日。日付のみの文字列として保持 |
| `employeeId` | 社員ID・必須 | 架空マスタ選択。認証とは別 |
| `siteId` | 現場ID・必須 | 架空マスタ選択 |
| `work` | 文字列1〜1000文字・必須 | 作業内容 |
| `start` / `end` | `HH:mm`・必須 | 同日内の出勤／退社。日またぎは要確認 |
| `breakMinutes` | 0以上の整数・必須 | 休憩分数。勤務区間より小さいこと |
| `hauls` | 運搬明細配列・必須 | 0件以上。運搬なしは空配列 |
| `fuels` | 給油明細配列・必須 | 0件以上。給油なしは空配列 |

参考実働 `workedMinutes` は `end−start−breakMinutes` から都度計算し、日報の手入力項目・独立保存値にしない。1分単位で扱い、丸め、所定内／残業／深夜／休日の区分は行わない。

## 現在：運搬明細 `Haul`

| 項目 | 型・必須 | 意味 |
| --- | --- | --- |
| `id` | 文字列・必須 | 明細の一意ID。日報を修正しても保持 |
| `from` | 文字列1〜200文字・必須 | 出発地。後続では現場IDや拠点IDとの対応を検討 |
| `destinationId` | 処分場ID・必須 | 運搬先。一般配送先は未対応 |
| `materialId` | 材種ID・必須 | 木くず、混合、RCガラなど |
| `quantity` | 0より大きい数・必須 | 運搬数量。台の場合は整数 |
| `unit` | `m3` / `t` / `trip`・必須 | m³・重量t・台（運搬回数）。相互換算しない |
| `assetId` | 車両ID・必須 | 車両マスタ参照。試作では重機も同じ選択元 |
| `driverId` | 社員ID・必須 | 実際の運転手。日報の社員と別指定可能 |

作業日・現場・日報IDは親日報から導出する。試作では台数とm³の同時記録はできない。同じ運搬を単位違いで二重登録せず、実用版の数量・計量票・台数の持ち方をQ09で確認する。

## 現在：給油明細 `Fuel`

| 項目 | 型・必須 | 意味 |
| --- | --- | --- |
| `id` | 文字列・必須 | 明細ID |
| `assetId` | 車両／重機ID・必須 | 給油対象 |
| `liters` | 0より大きい数・必須 | 給油量L |

作業日・現場・日報IDは親日報から導出。燃料種別、単価、給油所、走行距離、稼働時間、社内タンク入出庫はQ10。

## 現在：仮マスタ

`src/data/demo.js` に `employees`、`sites`、`assets`、`destinations`、`materials`、`units` を定義。各項目は `{ id, name }`。社員番号は試作では社員IDと同じ値。表示名を参照キーにしない。

## 集計先への対応

| 元データ | 集計先 | キー・計算 | 未確定値 |
| --- | --- | --- | --- |
| 日報の作業日・社員・現場・時刻 | 出勤簿 | 日報単位で出退勤／休憩／参考実働を表示 | 残業、休日、欠勤、休暇 |
| 日報の作業日・社員・参考実働 | 給与資料 | 社員×月の参考実働合計、作業日の重複を除いた日数 | `amount: null`、計算状態は要確認 |
| 運搬明細＋親の日付／現場 | 運行管理 | 運搬明細を一覧化。`reportId`を保持 | 距離、時刻、車両点検等 |
| 運搬明細の数量 | 処分費 | 現場×処分場×材種×単位で合計 | `amount: null`、単価・計量基準は要確認 |
| 給油明細のL数 | 燃料管理 | 車両／重機ごとに合計、元明細と`reportId`を保持 | 燃料代・燃費 |

月フィルターは集計前に適用。全期間でも給与資料は月別に分ける。数量は試作用の小数第3位で丸めるが、実際の請求用の精度・丸め方法は未確定。

| エンティティ候補 | 主な追加項目／関係 | 要確認 |

| 処分単価 | 処分場、材種、単位、適用開始／終了日、税区分、金額 | Q09。一般社員から変更不可とする範囲も確認 |

想定関係は「社員 1対多 日報」「日報 1対多 運搬／給油」「現場・車両・処分場・材種はIDで参照」。DB製品とテーブル定義は未決定。マスタ削除時の履歴維持、二重送信対策、同時編集、認証情報と社員情報の分離は保存処理の実装時に設計する。
