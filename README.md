# camany — 株式会社新開組 業務管理アプリ

従業員の日報を入力元に、出勤簿・給与資料・運行管理・処分費・燃料管理へつなぐアプリの初期構成。

**現在は要件確認用の試作（v0.1）。架空データで画面と連動を確認できる。実業務用の保存・ログイン・給与計算は未実装。**

## まず動かす

必要なもの：Git、Node.js 24.x（npmを含む）、ブラウザ。Windows 11のPowerShellでも同じコマンドを使える。

```sh
git clone https://github.com/shink7314-cmyk/camany.git
cd camany
node --version
npm start
```

表示された **http://127.0.0.1:3000** を開く。終了は `Ctrl+C`。

- 外部パッケージへの依存はなく、`npm install` は不要。
- WindowsでPowerShellが `npm.ps1` の実行を拒否する場合は `npm.cmd start`、`npm.cmd test` を使う。
- 3000番が使用中なら、PowerShellでは `$env:PORT=3001`、続けて `npm start`。macOS/Linuxでは `PORT=3001 npm start`。
- 「架空サンプル2件を読み込む」→各管理画面を選ぶと連動を確認できる。
- 初期サンプルは2026年11月。月の絞り込みを変えると表示対象も変わる。
- 入力はブラウザのタブのメモリ内のみ。再読み込み・終了で消え、他の端末とも共有されない。
- 開発サーバーはPC自身からだけ接続できる。iPhone相当の表示はブラウザの開発者ツールで確認可能。実機共有・社外アクセスは認証と保存先の決定後に対応する。

## 今回できること

| 機能 | 初期試作の範囲 |
| --- | --- |
| 日報 | 日付・社員・現場・作業内容・出退勤・休憩、複数の運搬／給油明細を入力・修正 |
| 出勤簿 | 日報ごとの参考実働時間（退社−出勤−休憩、分単位）を表示 |
| 給与資料 | 月別・社員別の参考実働・記録上の出勤日数。支給額は「要確認」 |
| 運行管理 | 日報の運搬明細を表示。運転手を日報入力者とは別に指定可能 |
| 処分費 | 現場・処分場・材種・単位別の数量集計。金額は「要確認」 |
| 燃料管理 | 車両・重機別L数と給油明細を表示 |

**未実装：** 認証・サーバーでの権限制御・共有DB・提出／承認・給与額／残業／控除計算・処分単価管理・バックアップ・Excel/PDF出力・音声入力・写真添付・オフライン同期。社員の選択欄はログインではない。

## 初期フォルダ

| パス | 役割 |
| --- | --- |
| `public/` | 画面のHTMLとスマートフォン対応CSS |
| `src/ui/` | 入力・画面切替・メモリ内の状態管理 |
| `src/domain/` | 入力検証と台帳への集計処理 |
| `src/data/` | 架空データと仮マスタ |
| `scripts/` | ローカル専用の起動スクリプト |
| `tests/` | 時間・重複・単位・連動・配信範囲のテスト |
| `docs/` | 要件、設計、未確定事項、開発手順 |

```sh
npm test
npm run check
```

公開リポジトリにはソースと架空データのみを保存する。実際の社員情報・給与・顧客・現場住所・帳票・認証情報は入れない。社内規定や金額を推測せず、未確定部分は [要確認事項](docs/open-questions.md) で管理する。

次は認証・権限、保存先、日報の提出／修正方法を確認し、共有保存できる日報から順に実装する。給与額と処分金額の確定は、それぞれのルール決定後に行う。
